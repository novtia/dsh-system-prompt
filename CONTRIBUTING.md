# Contributing

Add the GitHub topic `dsh-plugin` on this repository (Settings → Topics).

To list the plugin in dsh-market, open a pull request against [awesome-dsh-plugin](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin) that copies `docs/awesome-dsh-plugin.yml` to `data/plugins/novtia__dsh-system-prompt.yml`, then run `node scripts/generate-readme.mjs` there. Do not open a plugin-entry PR against [dsh-market/dsh-market](https://github.com/dsh-market/dsh-market).
